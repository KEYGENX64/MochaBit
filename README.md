# MochaBit - React + Vite + Tailwind migration

این شاخه نسخهٔ واکنش‌پذیر پروژه با React، Vite و Tailwind است.

دستورات:
- نصب: `npm install`
- توسعه: `npm run dev`
- ساخت: `npm run build`
- پیش‌نمایش: `npm run preview`

نکات:
- فونت‌ها و تصاویر باید در `src/assets/...` قرار بگیرند. مسیرهای داخل `src/index.css` و `src/data/products.json` قابل تغییر هستند.
